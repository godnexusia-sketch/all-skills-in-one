# All Skills In One — a mega-skill que contém todas as outras

Esta é uma **skill-índice**: uma única skill que empacota **as 953 skills desta coleção, sem exceção**.
Cada skill real vive em `skills/<nome>/SKILL.md` com seus próprios scripts e recursos, e continua
funcionando de forma independente. Esta SKILL.md serve como o catálogo e o ponto de entrada.

## Compatibilidade entre agentes
O formato `SKILL.md` (frontmatter YAML `name` + `description` e corpo em Markdown) é portátil. Esta
coleção foi montada para rodar em:
- **Claude Code** — instale como plugin (ver README) ou copie `skills/` para `~/.claude/skills/`.
- **OpenAI Codex / Cursor / Gemini CLI / outros** — use `npx skills add <owner>/all-skills-in-one`
  (CLI do ecossistema de skills) ou aponte o diretório de skills do seu agente para `skills/`.

## Como usar
1. Para achar a skill certa, procure no índice abaixo por "nome — responsável por ...".
2. Acione a skill pelo nome (ex.: `/find-skills`, `/reverse-engineer-anything`, `/code-review`).
3. Para descoberta automática de skills faltantes, use `find-skills`; para achar + instalar +
   rodar em um passo, use `skill-autopilot`.
